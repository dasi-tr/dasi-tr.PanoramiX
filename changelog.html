HymmShot Public Beta

The current Windows screenshot workflow for capturing, reviewing, editing, protecting and exporting.

Current release: Public Beta

  • Windows scrolling capture for scrollable application areas.
  • Built-in screenshot editor and support for opening existing PNG images.
  • Capture Issue Review with detected locations, Previous / Next navigation, Hide issues and Recapture.
  • Privacy-focused pixelation and blur.
  • Precise crop, transparent highlight and freehand drawing.
  • Arrows, rectangles, circles, check / X markers and text annotations.
  • Image saving and continuous single-page PDF export.
  • Support for long captures and real Windows workflows.
