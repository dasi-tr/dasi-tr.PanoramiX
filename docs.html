HymmScroll guide

Capture one long scrolling view.

  1. Install. Get HymmScroll from its official Microsoft Store listing.
  2. Select. Press Ctrl + Shift + X to start HymmScroll, then drag over the part of the window that scrolls.
  3. Scroll. Move through the content at your own pace.
  4. Finish. Press Enter or choose Finish to build one continuous image.
  5. Edit. Crop, blur or pixelate private details, highlight, draw, add arrows, shapes or text.
  6. Export. Save as an image or continuous single-page PDF.

HymmStack guide

Combine separate areas into one image.

  1. Install. Get HymmStack from its official Microsoft Store listing.
  2. Select an area. Press Ctrl + Shift + A to start HymmStack, then capture any part of any window.
  3. Add more. Capture another area from the same app or somewhere else.
  4. Combine. HymmStack turns the captures into one image.
  5. Edit. Crop, blur, highlight, add text, draw, erase or use shapes.
  6. Share. Copy to the clipboard, save an image or export a PDF.
Get HymmStackFull product page

Keyboard shortcuts.

HymmScroll: Ctrl + Shift + X  ·  HymmStack: Ctrl + Shift + A. Use these shortcuts to start the corresponding capture workflow on Windows.

Privacy tools are part of the workflow.

Both products are designed so you can blur or hide sensitive information before the screenshot leaves your computer.
