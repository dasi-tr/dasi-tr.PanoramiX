Capture, edit and export with HymmShot.

Learn how to capture a long scrollable Windows area, edit the result and export it with HymmShot.

1. Download and open the Windows beta

Use the official download link below. The current beta is distributed as a ZIP file from the project’s GitHub Releases page.

Download HymmShot for Windows

2. Select the scrollable area

Open HymmShot and draw a frame around the part of the Windows application you want to capture. This can be a browser, IDE, Terminal, CMD, log viewer, chat or another scrollable window.

3. Scroll through the content

Scroll normally through the selected area. HymmShot collects the content and combines it into one continuous image.

4. Finish, edit and export

Press Enter or Finish. The completed capture opens in the built-in editor, where you can crop, pixelate, highlight, draw, add arrows, shapes or text, save the image, or export it as a continuous PDF page.

Common questions

Does it work outside a browser?
Yes. HymmShot is designed for scrollable areas in Windows applications.

Why does Windows show a warning?
The current beta is not digitally signed. See the security page before launching it.
