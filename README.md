# HymmShot — Screenshot tools for Windows

HymmShot is a growing family of focused screenshot tools for Windows 10 and 11.
Everything runs locally on your PC: no account, no cloud upload.

🌐 Website: https://hymmshot.com

## Tools

### HymmScroll — scrolling screenshots
Capture content that continues below the screen (long web pages, chats, documents, logs, dashboards) as one continuous image. You scroll at your own pace while HymmScroll captures.

- Built-in editor: crop, blur/pixelate, highlight, draw, shapes, text
- Save as an image or as a single continuous PDF page
- Shortcut: **Ctrl + Shift + X**
- Get it free on the Microsoft Store: https://apps.microsoft.com/detail/9n6580jqmpw8

### HymmStack — multi-area capture
Capture separate areas from different windows or steps and combine them into one clear image.

- Edit and blur before sharing
- Copy, save or export the result
- Shortcut: **Ctrl + Shift + A**
- Get it free on the Microsoft Store: https://apps.microsoft.com/detail/9p1lzh1rvsdb

## Privacy
Capture and editing happen entirely on your computer. HymmShot tools work offline and do not upload screenshots anywhere.
