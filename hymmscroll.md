# HymmScroll — scrolling screenshots for Windows

> HymmScroll captures long web pages, WhatsApp Web conversations, documents, research, legal records, dashboards, code and more as one continuous screenshot in Windows. The user scrolls; HymmScroll stitches the result into a single image.

Page: https://hymmshot.com/hymmscroll/ · Microsoft Store: https://apps.microsoft.com/detail/9n6580jqmpw8 · Currently free · Contact: contact@hymmshot.com

## How it works
1. Start a capture and drag to select the scrollable area.
2. Scroll through the content at your own pace; you decide what is included and where it ends.
3. Press Enter or Finish. The editor opens with one continuous image.

## Where it works
Like a regular screenshot: if it is visible on screen, it can be captured. Browsers, WhatsApp Web and WhatsApp Desktop, Teams, documents, research, dashboards, IDEs, Terminal, logs and other Windows apps. It is not a browser extension.

## Editor
Blur and pixelate, highlight, arrows and shapes, text notes, crop. Export as an image or as one continuous single-page PDF. Existing PNG files can be opened and edited with the same tools. A capture review points out areas that may need attention, with an option to recapture.

## Who it is useful for
Lawyers and legal teams capturing long records or conversations; content editors and marketers saving source material; support teams documenting chats and workflows; researchers and students preserving long references; QA engineers and developers capturing logs, code and diagnostics; and anyone who needs one continuous image instead of a sequence of screenshots.

## Privacy
Capturing and editing happen locally on the user's Windows PC. No upload, no account.
