# HymmShot — screenshot tools for Windows

> HymmShot is a growing family of focused screenshot tools for Windows. Each tool is built around one capture workflow, and every tool works fully offline: captures are created and edited on the user's own PC, with no account and no cloud upload.

Website: https://hymmshot.com/ · Contact: contact@hymmshot.com

## Tools

### HymmScroll — scrolling screenshots for Windows
Captures content that continues past the edge of the screen as one continuous image: long web pages, WhatsApp Web conversations, documents, research, legal records, dashboards, code and more, in Windows apps and websites. The user selects the area and scrolls manually, so they control exactly what goes into the capture and where it ends.
- Page: https://hymmshot.com/hymmscroll/
- Microsoft Store: https://apps.microsoft.com/detail/9n6580jqmpw8
- Price: currently free
- Previously released under the name HymmShot

### HymmStack — combine multiple screenshots into one image
Captures several separate areas, one after another, from different windows, apps or steps, and combines them into a single image for legal work, content, research, support, QA or everyday sharing.
- Page: https://hymmshot.com/hymmstack/
- Microsoft Store: https://apps.microsoft.com/detail/9p1lzh1rvsdb

## Built-in editor (both tools)
Blur and pixelate private details, highlight, pen, eraser, arrows and shapes, text notes, crop, undo and redo. Export: copy to clipboard, save as an image, or export as PDF. HymmScroll can export a long capture as one continuous single-page PDF.

## Privacy
Capturing and editing happen locally on the user's Windows PC. No account is required and nothing is uploaded to a cloud service to process screenshots. Installed and updated through Microsoft Store.

## Who it is for
Lawyers and legal teams, content editors and marketers, customer support teams, researchers and students, technical writers, QA engineers and developers, and everyday users who would rather share one clear visual than several disconnected screenshots.

## Common questions
**What is HymmShot?** A growing family of focused screenshot tools for Windows. The current tools are HymmScroll for scrolling captures and HymmStack for combining separate captures.
**Which tool do I need?** Content longer than the screen in one place: HymmScroll. Content spread across several places: HymmStack.
**Do the tools upload screenshots?** No. Everything happens on the user's own computer.
**Where do I download them?** Microsoft Store, links above.
