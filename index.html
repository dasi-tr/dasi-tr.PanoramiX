How it works

From a long window to a finished result.

The capture stays simple. The editing tools are there only when you need them.

1

Select the area

Open HymmShot and draw a frame around the scrollable content you want to capture.

2

Scroll through the content

Scroll normally. HymmShot follows the selected area and collects the content.

3

Finish the capture

Press Enter or Finish. HymmShot combines the scroll into one continuous image.

Frequently asked questions

The practical details.

What is HymmShot?

HymmShot is a Windows scrolling screenshot tool. It captures a selected scrollable area, combines the content into one continuous image and opens the result in a built-in editor.

Does HymmShot work outside the browser?

Yes. It is designed for scrollable areas in Windows applications, including browsers, IDEs, Terminal, CMD, logs, chats and other windows.

Does the editor replace the scrolling capture?

No. Scrolling capture remains the core feature. The editor starts after HymmShot has finished combining the captured content.

Can I hide sensitive information?

Yes. The built-in pixelation tool changes the selected pixels rather than placing a cosmetic translucent layer over them.

Can I export the long screenshot to PDF?

Yes. HymmShot can export the result as a clean, continuous single-page PDF.

Is HymmShot free?

The current Windows beta is available as a free download.

Why does Windows show a warning?

The beta is not digitally signed yet. When using the official download, Windows may require selecting More info → Run anyway.
